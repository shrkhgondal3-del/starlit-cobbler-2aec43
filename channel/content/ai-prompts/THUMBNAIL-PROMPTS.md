# Saudi Gateway — AI Thumbnail Prompt Library

Generate base images in **Ideogram**, **DALL-E**, or **Midjourney**. Add text in **Canva** (never rely on AI for text — it garbles).

---

## Brand Rules for All Thumbnails

- Background: deep navy `#0D1B2A` or dark gradient
- Accents: Saudi green `#006C35`, desert gold `#C5A572`
- **No faces** unless using consistent HeyGen avatar across all thumbnails
- Leave **right 50%** relatively clear for text overlay in Canva
- Aspect: 16:9 (1280×720 final)

---
